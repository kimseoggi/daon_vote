# 행운의 추첨 - 안드로이드 설치 패키지

## 설치 방법
1. 이 폴더의 파일을 모두 HTTPS를 지원하는 웹 호스팅에 올립니다. (예: GitHub Pages)
2. 안드로이드 휴대폰/태블릿의 Chrome에서 배포된 주소를 엽니다.
3. 오른쪽 위 메뉴(점 3개) → "앱 설치" 또는 "홈 화면에 추가"를 누릅니다.
4. 홈 화면의 "행운의 추첨" 아이콘으로 실행합니다.

## 주요 기능
- 회원명단 직접 등록 및 엑셀 첫 번째 열 붙여넣기
- 응모 화면에서 이름을 누를 때마다 비프음 및 응모권 추가 (같은 회원 중복 응모 가능)
- 서로 다른 응모자 3명 당첨 추첨, 3초 연출, 결과 발표 시 팡파르 효과음
- 추첨 결과 초기화 시 응모권 유지
- 명단입력 / 응모 / 추첨 화면은 각 단추를 눌렀을 때만 표시
- 첫 방문 이후 오프라인 실행 지원

## 참고
- 이 패키지는 웹 앱(PWA)입니다. 서명된 설치 파일(.apk)은 포함하지 않습니다.
- 비프음이 나지 않으면 화면을 한 번 터치한 뒤 다시 눌러 보세요.
- 회원명단, 응모권, 당첨 결과는 해당 기기 브라우저의 저장소에 저장됩니다. 사이트 데이터 삭제 시 사라질 수 있으니 행사 전에 테스트해 보세요.
